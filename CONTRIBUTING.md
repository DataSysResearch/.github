# Contributing to DataSys

Thank you for your interest in DataSys.

DataSys projects focus on open-source data management and processing for continuously evolving data, including streams, dynamic graphs, vector/ANNS systems, online indexes, reproducible benchmarks, and data lifecycle infrastructure.

Each project may maintain its own contribution workflow. Before opening a pull request, please read the target repository's README, issue tracker, license, and maintainer guidance.

## Project Scope

A repository belongs in DataSys when it provides framework-neutral data-system functionality or benchmarks. SAGE-facing adapters, agent/RAG workflows, model-runtime systems, compiler/runtime kernels, and hardware-execution projects should remain in their corresponding ecosystem organizations unless maintainers explicitly decide on a split.

## Pull Requests

- Keep changes focused and reviewable.
- Include tests or reproducibility notes when behavior changes.
- Update documentation for public APIs, command-line usage, experiments, and benchmark results.
- Preserve citation and artifact-evaluation instructions for research repositories.

## Maintainers

Maintainers should document supported environments, release status, issue triage expectations, and project ownership in the repository README or maintainer docs.
